# ⚡ ScanDesk Pro — Next-Gen QR & Barcode Mobile Suite

A fast, private, offline-first cross-platform scanner & generator built with modern mobile design, interactive samples, and zero-telemetry local storage.

---

## 🌟 Key Highlights

- 📷 **Real-Time Live Camera Scanner**: High-speed viewfinder with animated laser line, front/rear camera switcher, and torch support.
- 🖼️ **Photo & Gallery Scanner**: Instant drag-and-drop or file upload barcode decoding.
- ✨ **Interactive Demo Samples**: 1-Tap test samples (Wi-Fi network, Contact Card, Safe Website Link, EAN-13 Product Barcode).
- 🛠️ **QR Studio**: Real-time generation of custom QR codes (URLs, Wi-Fi, Contacts, Text, Phone) with 1-click PNG download.
- 📜 **Local Storage & History**: Private history with star favorites, notes, and instant search.
- 📱 **WhatsApp Instant Mobile File (`ScanDesk-Mobile.html`)**: Send via WhatsApp to any phone (Android/iOS) — taps to open directly in Chrome/Safari with zero installation required!

---

## 🚀 Quick Start

### Option 1: 1-Click Windows Run
Double-click `start.bat` to launch the interactive application.

### Option 2: Instant WhatsApp Share to Mobile Phone
Send `ScanDesk-Mobile.html` on WhatsApp. Opening it in Chrome or Safari immediately launches the mobile camera scanner!
