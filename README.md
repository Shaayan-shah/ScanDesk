# ScanDesk

ScanDesk is a browser-based QR code and barcode scanner and QR code generator. Scan with a device camera or select an image, then create QR codes for common uses such as links, contact details, Wi-Fi access, and text.

[Open ScanDesk](https://shaayan-shah.github.io/ScanDesk/dist/)

## Features

- Scan codes using a device camera or an image from your photo library.
- Create QR codes for URLs, text, phone numbers, contacts, and Wi-Fi networks.
- Review recent scans, add notes or favourites, and search local history.
- Use the application on desktop or mobile browsers.

## Use on a phone

Open the web app in a supported mobile browser and allow camera access when prompted. You can add the site to your home screen using your browser's install or add-to-home-screen option where available.

## Run locally

On Windows, run `start.bat` from the repository root. The development server starts at `http://localhost:5173`. For other environments, install the dependencies with `npm install` and follow the scripts in `package.json`.

## Privacy

ScanDesk is designed to process scans in the browser and keep scan history in local storage. The hosted version requires an internet connection to load; camera access depends on browser permissions and a secure context.
